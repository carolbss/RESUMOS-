🧭 Definição

📏 Mecanismo

Contuso 🚗 × Penetrante 🔪

contuso = machuca víscera maciça (baço/fígado) · penetrante = machuca víscera oca (tripas) 🌀

🎯 Órgão + lesado
  • 🚗Contuso → Baço
  • 🔫Arma de fogo → Delgado
  • 🔪Arma branca → Fígado

🔊 FAST

📡 4 janelas
  • ❤️Pericárdica (subxifoide)
  • 🫘QSD — Morison (+ sensível no supino ⭐)
  • 🩸QSE — esplenorrenal
  • 🔽Pélvica (Douglas)

e-FAST = + 2 janelas do tórax (hemo/pneumotórax) 🫁

⭐ Alto rendimento
  • 📈Sensib. ~85–96% · espec. >98% (líquido livre, ≥200 mL)
  • 🚫NÃO vê: víscera oca, retroperitônio, diafragma
  • ⚠️FAST negativo NÃO exclui lesão!

📐 Algoritmo

Inst +FAST + → 🏥 laparotomia JÁ (sem TC)
Inst –FAST – → busca outra fonte / DPL
Estáv +FAST + → 🖥️ TC gradua → NOM × cx
Estáv –FAST – → observação / TC
🚨 Laparotomia JÁ
  • 🩸Instável + FAST/DPL +
  • 🔥Peritonite
  • 🫃Evisceração / empalamento
  • 💨Pneumoperitônio · diafragma · bexiga intraperit.
  • 🔫PAF transperitoneal

🛡️ NOM & graus

✅ Manejo não operatório
  • 🫀Estável + baço/fígado por TC, sem peritonite
  • 🎯Blush/pseudoaneurisma → angioembolização
  • ⚠️Quem decide cirurgia é a hemodinâmica, não o grau!
AAST I-IIBaixo grau → NOM 🟢
AAST IIINOM se estável 🟡
AAST IV-VAlta falha; ⅔ operam se instável 🔴

2018: grau sobe se houver lesão vascular (blush/pseudoaneurisma) 📈

📍 Retroperitônio

⭐ Zonas — decorar!
  • 1️⃣Zona I (central) → SEMPRE explora (aorta/VCI/duodeno-pâncreas)
  • 2️⃣Zona II (flanco) → explora se penetrante / expansivo
  • 3️⃣Zona III (pelve) → contuso NÃO abre (empacota + angio 🎯)

🛠️ Damage Control

💀 Tríade letal (HAC)
  • 🌡️Hipotermia <35°C
  • 🧪Acidose pH <7,2
  • 🩸Coagulopatia
  • 💎(+ hipoCalcemia = diamante letal)

3 fases ⏱️

1
Abre (abreviada) — packing + ligadura + shunt · alça grampeada sem anastomose · peritoneostomia 🩹
2
Reanima (UTI) — reaquece, corrige acidose/coagulopatia 🔥
3
Reconstrói — 24–48 h · anastomose + fecha parede 🧵
🩸 DCR
  • 📉Hipotensão permissiva (~80–90 mmHg)
  • ⚖️Transfusão 1:1:1 · pouco cristaloide
  • ⏰TXA <3 h (1g+1g)
  • 🎈REBOA = ponte, não solução

🔪 Técnica

🛏️ Setup

Supino crucifixo · antissepsia mento → coxa · mediana xifopúbica 📏

1
Abre + aspira coágulos Eafastador Dbisturi
2
Packing 4 quadrantes 🩹 tampona e revela a fonte
3
Hemostasia: packing peri-hepático · Pringle (pedículo hepático) 🤏
4
Baço instável → esplenectomia (hilo com seda 2-0/0) 🩸
5
Alça lesada → grampeia, sem restaurar trânsito ✂️
🧵 Fios
  • ·Pedículo/vaso calibroso → seda/poliéster 2-0/0
  • ·Enterorrafia (definitiva) → PDS/Vicryl 3-0/4-0
  • ·Vaso reparável → prolene 4-0/5-0 · aponeurose → PDS 1

🪤 Pega-ratões

⚠️ Não erre!
  • 🚫FAST – NÃO exclui lesão
  • 🖥️Instável + FAST + → sala, não pede TC
  • 🟢FAST + no estável ≠ cirurgia (gradua por TC)
  • 📊Grau AAST alto não indica cirurgia — é a fisiologia
  • 1️⃣Zona I sempre abre · Zona III contuso não abre
  • 🧵Damage control = sem anastomose na 1ª cx
  • ⏰TXA só <3 h
  • 🫁Diafragma E passa batido → herniação tardia
